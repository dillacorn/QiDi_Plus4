## Local calibration settings used

The following values were used only for personal calibration on a QiDi Plus4 and are not part of the original model license:

- Firmware command: `M900 K<value>`
- ABS / ASA test range: `0.015`, `0.035`, `0.055`, `0.075`
- TPU 95A test range: `0.040`, `0.070`, `0.100`, `0.130`
- Cancel behavior used for test prints: stop/cancel at layer 195
